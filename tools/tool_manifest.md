# Tool Manifest: The Surgical Suite

The following tools are recommended for a high-precision Analytics Engineering pipeline.

### 1. Data Extraction & Structuring
- **langstruct**: Prompt optimization and schema definition.
- **langextract**: High-precision extraction with source grounding.

### 2. Data Manipulation & Routing
- **Polars**: Fast, memory-efficient data transformation.
- **sqlglot**: SQL transpilation between dialects.
- **sqlfluff**: Deterministic SQL linting and verification.

### 3. Orchestration & Synthesis
- **ruflo**: Multi-agent swarm coordination for complex synthesis.
- **graphify**: Knowledge graph generation for routing.
