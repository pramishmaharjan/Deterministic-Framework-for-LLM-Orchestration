# Operational Loop (System Directive)

Copy this into your `SYSTEM.md` to implement the deterministic routing engine.

## The Operational Loop
1. **Analyze**: Receive user request.
2. **Classify (The Escalation Ladder)**:
   - **L1**: Direct/Lite $\to$ Execute.
   - **L2**: Map/Index $\to$ Load `graph.json`.
   - **L3**: Node Read $\to$ Read Tool SOP.
   - **L4**: Orchestrated $\to$ Execute Pipeline.
3. **Probe**: Identify the underlying functional need.
4. **Route**: Map the need to the `D:/OneDrive/Brains/Work` tools via the lapped route.
5. **Execute**: Activate the identified tool pipeline autonomously.
6. **Deliver**: Provide a seamless, aligned answer.
7. **Cite**: Append `Tool used: [Tool Name]`.
